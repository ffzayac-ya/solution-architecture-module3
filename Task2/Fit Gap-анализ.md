# 1 Список систем
## 1.1 Промежуточное решение
Участвующие существующие информационные системы и их функциональность:
- ИС «Алмазы»
	- Учет алмазов (существующая)
	- Оцифровка камней (существующая) - ручной ввод данных по результатам работы экспертов.
- ИС «Логистика»
	- Перевозка алмазов покупателям (существующая)
- ИС «Аукцион»
	- Ввод данных для проведения аукциона (существующая)
	- Проведение аукциона (существующая)
- ИС «Бухгалтерия»
	- Актирование (существующая)
	- Оплата услуг перевозчиков (существующая)
	- Ведение контрактов (существующая)

Новые информационные системы необходимые для реализации промежуточного решения и их функциональность:
- ПО Microsoft Excel
	- ручное составление ведомости камней для аукциона для выгрузки в облако
- Облачные сервисы
	- Загрузка данных из ИС "Аукцион" (новая) - загружаются данные в формате \*.xlsx в соответствии с согласованным шаблоном
	- Предоставление данных участникам аукциона (новая) - организация доступа к загруженным данным участникам аукциона
## 1.2 Целевое решение
Участвующие существующие информационные системы и их функциональность:
- существующие внутренние:
	- ИС «Алмазы»
		- Учет алмазов (существующая)
		- Отбор алмазов для цифрового аукциона (новая) - автоматизирует процесс составления ведомости камней для участия в аукционе
	- ИС «Логистика»
		- Перевозка алмазов покупателям (существующая)
		- Перевозка алмазов в лабораторию и обратно в офис (новая) - участвует в автоматизации процесса оцифровки камней в лаборатории
	- ИС «Аукцион»
		- Проведение аукциона (существующая)
		- Получение данных для проведения аукциона из ИС "Алмазы" (новая) - данные для проведения аукциона автоматически получаются из системы учета камней. Реализуется возможность выбора языка отображения данных из списка.
		- Статусная модель аукциона - событие аукциона имеет статусную модель в соответствии с процессом подготовки и проведения
		- Контрольные процедуры - изменение статуса аукциона сопровождается контролем за достаточностью и корректностью введенных данных на соответствующем этапе
		- Публикация данных для клиентов (новая) - функциональность, которая обеспечивает проведение аукциона онлайн. Потребуется обеспечить подключение ИС к сети интернет.
	- ИС «Бухгалтерия»
		- Актирование (существующая)
		- Оплата услуг перевозчиков (существующая)
		- Ведение контрактов (существующая)
		- Оплата услуг лаборатории (новая) - участвует в автоматизации процесса оцифровки камней в лаборатории
- внешние новые:
	- ИС "Лаборатория"
		- Оцифровка камней (новая) - заменяет ручной труд экспертов на автоматический процесс оцифровки в информационной системе
# 2 Список интеграций
## 2.1 Промежуточное решение
Промежуточное решение не подразумевает доработки существующих или реализации новых интеграционных взаимодействий.

Существующие интеграционные взаимодействия:
- ИС «Алмазы» → ИС «Логистика»: передача данных о камнях по результатам проведенного аукциона для планирования и перевозки алмазов покупателям.
- ИС «Логистика» → ИС «Бухгалтерия»: автоматическая передача данных о перевозках для составления актов и оплаты услуг транспортной компании по перевозке камней покупателям.

Для предоставления данных участникам аукциона реализуется ручной процесс выкладывания на облачный ресурс файла/файлов в формате \*.xlsx.
## 2.2 Целевое решение
Целевое решение предполагает высокий уровень автоматизации процессов компании за счет реализации новых и расширения существующих интеграционных взаимодействий.

Существующие интеграционные взаимодействия, для которых потребуются доработки:
- ИС «Алмазы» → ИС «Логистика» (файловый обмен): автоматическая пакетная передача данных о результатах аукциона для планирования и перевозки алмазов покупателям. Т.к. результаты аукциона будут получены автоматически из ИС "Аукцион", потребуется доработка существующей интеграции.
- ИС «Логистика» → ИС «Бухгалтерия» (асинхронное взаимодействие, брокер сообщений): актирование и оплата услуг транспортной компании по перевозке камней покупателям. Интеграция расширяется для реализации функции оплаты услуг по перевозке камней в лабораторию и обратно в хранилище.

Новые интеграционные взаимодействия:
- ИС «Лаборатория» → ИС «Алмазы» (потоковая передача данных): автоматическое получение данных о камнях и передача описания алмазов по результатам исследования и оценки.
- ИС «Лаборатория» → ИС «Бухгалтерия» (асинхронное взаимодействие, брокер сообщений): данные для актирования и оплата услуг лаборатории.
- ИС «Лаборатория» → ИС «Логистика» (файловый обмен): автоматическая пакетная передача данных по расписанию об окончании исследований для планирования и перевозки алмазов обратно в хранилище.
- ИС «Алмазы» → ИС «Аукцион» (файловый обмен): реализуется автоматическая выгрузка данных о камнях для проведения аукциона. Результаты аукциона также автоматически передаются в систему учета камней для дальнейшего планирования доставки покупателям.
